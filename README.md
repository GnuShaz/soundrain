# SoundRain

Нативный десктопный клиент для SoundCloud на Tauri и Rust.

SoundRain проигрывает треки SoundCloud напрямую через нативный аудио-движок, без встраивания веб-плеера. В приложении — очередь воспроизведения, лайки, поиск, страница исполнителя, 10-полосный эквалайзер, поддержка системных медиа-клавиш, трей с мини-плеером, виджет «Сейчас играет» для OBS и статус в Discord.

## Возможности

- Воспроизведение через нативный аудио-движок на Rust (rodio), а не встроенный веб-плеер
- Очередь, поиск (по трекам и плейлистам), лайки, страница исполнителя с его треками и плейлистами
- 10-полосный эквалайзер в реальном времени с пресетами
- Поддержка системных медиа-клавиш и центра уведомлений Windows
- Иконка в трее и отдельное компактное окно мини-плеера
- Своя фоновая картинка и выбор аудиоустройства вывода
- Прямое соединение, системный прокси или интеграция с [zapret](https://github.com/Flowseal/zapret-discord-youtube) для доступа из сетей с блокировками
- Локальный HTTP-виджет «Сейчас играет» для Browser Source в OBS
- Статус прослушивания в Discord (Rich Presence)
- Локальный дисковый кэш прослушанных треков с настраиваемым лимитом

## Стек

**Десктопное приложение**
Tauri 2 (Rust) · React 19 · TypeScript · Vite 7 · Tailwind CSS 4 · Zustand · TanStack Query · Radix UI · rodio

**Бэкенд**
NestJS 11 · TypeORM · PostgreSQL

Бэкенд — вспомогательный сервис для хранения лайков, очереди и позиции воспроизведения между запусками. Сам плеер полностью работает и без него — недоступной останется только эта персистентность, если бэкенд не настроен.

## Разработка

Понадобятся: Node.js с `pnpm` (через Corepack), Rust и Docker (для PostgreSQL бэкенда).

```
pnpm install

# десктопное приложение
cd apps/desktop
pnpm tauri dev

# бэкенд
docker compose up -d
cd apps/server
cp .env.example .env
pnpm dev
```
